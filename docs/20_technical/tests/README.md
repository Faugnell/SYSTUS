# Tests manuels

Ce dossier decrit les validations a faire sur Raspberry Pi.

Suites conseillees :

- Test micro I2S : detection ALSA, niveau d'entree, fichier WAV lisible.
- Test reconnaissance : extrait connu, extrait bruite, absence de match.
- Test e-ink : rafraichissement texte, image, contraste, latence.
- Test boutons : appui court, appui long, rebond, sortie de veille.
- Test Wi-Fi : premiere configuration, reconnexion, portail local.
- Test autonomie : comportement avec UPS HAT et batterie.
