# Software

Ce dossier documente les choix logiciels, les commandes d'installation et les
services Linux.

Contenu conseille :

- `installation-raspberry-pi.md` : installation systeme et dependances.
- `configuration.md` : variables `.env`, fichiers YAML ou JSON.
- `services.md` : services systemd et ordre de demarrage.
- `api-locale.md` : routes web locales et payloads principaux.
- `reconnaissance-musicale.md` : moteur choisi, contraintes et alternatives.
