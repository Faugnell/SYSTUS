# Documentation technique

Ce dossier contient les elements utiles a la conception et a l'integration du
prototype.

```text
20_technical/
├── architecture/           # Architecture systeme et logicielle
├── hardware/               # CAO, croquis, schemas electriques, BOM
├── software/               # Choix logiciels, API locales, services Linux
└── tests/                  # Protocoles de tests manuels sur Raspberry Pi
```

Priorite de documentation :

1. Schema de fonctionnement global.
2. Liste materielle et branchements.
3. Architecture logicielle minimale.
4. Procedure d'installation Raspberry Pi.
5. Tests manuels de chaque module.
