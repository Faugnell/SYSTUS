# Hardware

Ce dossier rassemble les documents materiels du prototype.

```text
hardware/
├── cad/                    # Modeles 3D, CAO, exports STEP/STL
├── sketches/               # Croquis, recherches de forme, design cassette
├── electronics/            # Schema electrique, brochage, cablage
└── bom/                    # Nomenclature, fournisseurs, couts
```

Materiel cible :

- Raspberry Pi Zero ou Pi Zero W.
- Microphone MEMS I2S ICS-43434.
- Ecran e-ink.
- Boutons physiques.
- UPS HAT Waveshare avec batterie, micro USB et bouton on/off.
- Option future : carte MicroSD SPI.
